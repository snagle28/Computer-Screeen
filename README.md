This game is a final project for our intermediate game development class.
'Happy Cooking' (or Computer-Screeen) is a game about searching a cooking blog for a secret ritual recipe. 
It is a mashup between Anatomy and Welcome to the Game. Players solve puzzles by swapping words to create new meaning. 

Key mechanics implemented:
1. Setting up an in-game computer screen that players interact with.
    a) Using raycasting and pointer events to map interaction from the camera to a separate, UI canvas.
    b) Customizing drag events to allow user to scroll through recipe pages.
    c) Animating transitions between pages and using Unty button UI to guide players through the blog.
3. Creating custom glitch and static shaders.
4. Designing puzzles and levels.

What we learned:
1. How to use Unity's built-in event system and modify/customiz it to meet our needs.
2. How to use raycasting to create a dynamic, projected screen.
3. How to integrate art, design, and programmng to customize Unity UI (especially with buttons).
4. How to use Unity shader graphs.
